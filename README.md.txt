# FPGA-Based CNN Accelerator

## Project Overview
This project contains Verilog HDL source code for an FPGA-based neural network accelerator targeting the Zynq-7000 platform using the ZedBoard.

## Hardware Platform
- **Board:** ZedBoard
- **FPGA:** Xilinx Zynq-7000 (`xc7z020clg484-1`)
- **Development Tool:** Xilinx Vivado 2018.2
- **HDL:** Verilog

## Source Code
- `mnist_nn.v` — Verilog module for processing input pixel data using stored weights and biases to calculate scores for 10 output classes.

## Project Status
This repository currently contains a selected Verilog source file. Additional project files, simulation results, and hardware validation details can be added as they are prepared.
